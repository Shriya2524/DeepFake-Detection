================================================================================
                              SYSTEM OVERVIEW
================================================================================

The system has 5 main detection capabilities working together:

1. SPATIOTEMPORAL MODEL - Analyzes video frame sequences for temporal anomalies
2. GAN FINGERPRINT MODEL - Detects GAN artifacts in individual frames  
3. FUSION MODEL - Combines predictions from both models for final result
4. GAN FAMILY CLASSIFIER - Identifies which GAN made the fake (StyleGAN, ProGAN, etc.)
5. AI-GENERATED DETECTOR - Detects AI-generated images (DALL-E, Midjourney, etc.) - NEW!

Final accuracy: 98.33% (Deepfake) + Multi-Check Consensus (AI-Generated)

================================================================================
                         MODEL 1: SPATIOTEMPORAL MODEL
================================================================================

FILE: src/models/spatiotemporal_model.py
CHECKPOINT: checkpoints/spatiotemporal/best_model.pt

WHAT IT DOES:
- Takes video frames as input (sequence of images)
- Uses ResNet18 CNN to extract features from each frame
- Uses LSTM to analyze temporal patterns (how frames change over time)
- Looks at optical flow (motion between frames)
- Outputs: fake probability + attention scores showing which frames are suspicious

ARCHITECTURE:
  Video Frames (B, T, 3, 224, 224)
       |
       v
  ResNet18 Backbone --> Frame Features (B, T, 512)
       |
       v
  Optical Flow Encoder --> Motion Features (B, T, 128)
       |
       v
  Feature Projection (512+128 --> 256)
       |
       v
  Bidirectional LSTM (2 layers, hidden=256)
       |
       v
  Classification Head --> [Real, Fake] probabilities

WHY IT WORKS:
- Deepfakes have temporal inconsistencies (blinking, expressions)
- Real videos have natural motion flow
- The LSTM learns patterns that distinguish real vs fake temporal behavior

================================================================================
                        MODEL 2: GAN FINGERPRINT MODEL
================================================================================

FILE: src/models/gan_fingerprint_model.py
CHECKPOINT: checkpoints/gan_fingerprint/best_model.pt

WHAT IT DOES:
- Analyzes individual images/frames for GAN-specific artifacts
- Uses multi-channel input: RGB + YCbCr + DCT frequency + Edge maps
- Three specialized branches process different signal types
- Outputs: fake probability per frame

ARCHITECTURE:
  Input Image (224x224)
       |
       v
  Multi-channel preprocessing:
  - RGB (3 channels)
  - YCbCr color (2 channels: Cb, Cr)
  - DCT high frequency (1 channel)
  - Edge features: Sobel X, Sobel Y, Laplacian (3 channels)
  = Total: 9 channels
       |
       v
  EfficientNet-B0 Backbone (processes RGB + color)
       |
       v
  Frequency Branch (processes DCT)
       |
       v
  Edge Branch (processes edge maps)
       |
       v
  Feature Fusion (concatenate all branches)
       |
       v
  Classification Head --> [Real, Fake] probabilities

WHY IT WORKS:
- GANs leave fingerprints in frequency domain (checkerboard artifacts)
- Color channels (CbCr) show compression differences
- Edge patterns reveal texture inconsistencies
- Multiple signals combined = more robust detection

================================================================================
                          MODEL 3: FUSION MODEL
================================================================================

FILE: src/models/fusion_model.py
CHECKPOINT: checkpoints/fusion/best_model.pt

WHAT IT DOES:
- Takes outputs from Spatiotemporal and GAN Fingerprint models
- Combines them intelligently for final prediction
- Small MLP network (very fast)

INPUT FEATURES (5 values):
1. video_fake_prob - from spatiotemporal model
2. mean_frame_prob - average fake probability across all frames
3. std_frame_prob - variation in frame scores
4. max_frame_prob - highest frame score (most suspicious frame)
5. min_frame_prob - lowest frame score

ARCHITECTURE:
  5 Features
       |
       v
  Linear(5 --> 32) + ReLU + Dropout
       |
       v
  Linear(32 --> 16) + ReLU + Dropout
       |
       v
  Linear(16 --> 2) --> [Real, Fake] probabilities

WHY IT WORKS:
- Temporal and frequency signals complement each other
- Some fakes have temporal issues but clean frames (catches those)
- Some fakes have GAN artifacts but smooth motion (catches those too)
- Fusion learns optimal weighting automatically

================================================================================
                       MODEL 4: GAN FAMILY CLASSIFIER
================================================================================

FILE: src/models/gan_family_model.py
CHECKPOINT: checkpoints/gan_fingerprint_family/best_model.pt

WHAT IT DOES:
- Multi-class classification (not just Real/Fake)
- Identifies the SOURCE GAN that created the fake
- Classes: Real, StyleGAN, ProGAN, PGGAN, Other

ARCHITECTURE:
  Same as GAN Fingerprint but with 5-class output instead of 2
  
  Multi-channel Input (9 channels)
       |
       v
  EfficientNet-B0 + Frequency Branch + Edge Branch
       |
       v
  Feature Fusion
       |
       v
  Classification Head --> [Real, StyleGAN, ProGAN, PGGAN, Other]

OUTPUT:
- predicted_family: "StyleGAN" 
- confidence: 87.3%
- family_probs: {"Real": 5%, "StyleGAN": 87%, "ProGAN": 3%, ...}

================================================================================
                  MODEL 5: AI-GENERATED DETECTOR (NEW!)
================================================================================

FILE: src/api/ai_generated/multi_check_detector.py
MODEL: src/api/ai_generated/image_classifier_model.keras

WHAT IT DOES:
- Detects AI-Generated images vs Natural/Real photos
- Targets: DALL-E, Midjourney, Stable Diffusion, other AI generators
- Uses 5-point Multi-Check analysis for high accuracy
- Majority voting system for final decision

ARCHITECTURE (5 Independent Checks):

  Input Image
       |
       +---> Check 1: Neural Network (Keras CNN)
       |         - Trained binary classifier
       |         - Input: 128x128 RGB
       |         - Output: AI_prob, Natural_prob
       |
       +---> Check 2: Frequency Analysis (FFT)
       |         - 2D Fast Fourier Transform
       |         - High/Low frequency ratio
       |         - AI images have distinctive patterns
       |
       +---> Check 3: Noise Pattern Analysis
       |         - Variance of local variance
       |         - AI = uniform noise (high score)
       |         - Real = varied noise (low score)
       |
       +---> Check 4: Color Distribution Analysis
       |         - LAB color space entropy
       |         - HSV saturation variance
       |         - AI = uniform colors, less entropy
       |
       +---> Check 5: Edge Characteristics
       |         - Canny edge detection
       |         - Edge density and smoothness
       |         - AI edges are smoother
       |
       v
  Weighted Voting System
       |
       +---> Neural Network: 30%
       +---> Frequency Analysis: 20%
       +---> Noise Analysis: 18%
       +---> Color Distribution: 17%
       +---> Edge Analysis: 15%
       |
       v
  Final Score + Adaptive Threshold
       |
       v
  OUTPUT: AI_Generated or Natural

DECISION LOGIC:
  - If 3+ checks vote AI --> AI-Generated
  - If 4+ checks vote Natural --> Natural/Real
  - Unanimous agreement --> Very High confidence

CONFIDENCE LEVELS:
  - "Very High (Unanimous)" - All 5 checks agree
  - "High (Majority Agreement)" - 4+ checks agree
  - "High (Natural Majority)" - 4+ checks say Natural
  - "Medium" - 60%+ consensus
  - "Low" - Less than 60% consensus

WHY IT WORKS:
- Single method can be fooled, 5 methods are robust
- Different checks catch different AI signatures
- Frequency analysis detects mathematical patterns
- Noise analysis catches artificial uniformity
- Color/Edge analysis detects unnatural characteristics

================================================================================
                           TRAINING SCRIPTS
================================================================================

ROBUST FUSION TRAINING: train_fusion_robust.py

This script trains the Fusion model with automatic fallbacks:

FEATURES:
1. Automatic GPU -> CPU fallback if CUDA fails
2. Automatic batch size reduction on OOM errors
3. Multiple checkpoint fallback options
4. Memory cleanup between batches
5. Early stopping with patience

TRAINING PROCESS:
1. Load pre-trained Spatiotemporal model
2. Load pre-trained GAN Fingerprint model
3. Load video dataset from data/faceforensics/
4. Extract features from all videos using both models
5. Train small Fusion MLP on extracted features
6. Save best model based on validation loss

RUN COMMAND:
  python train_fusion_robust.py

================================================================================
                          INFERENCE PIPELINE
================================================================================

FILE: src/inference/pipeline.py

This is the main class that runs detection end-to-end.

CLASS: DeepfakeDetectionPipeline

METHODS:
- load_weights() - Load all model checkpoints
- detect_video() - Analyze a video file
- detect_image() - Analyze a single image
- set_threshold() - Change detection threshold

DETECT VIDEO FLOW:
1. Read video frames
2. Extract faces from frames
3. Compute optical flow between frames
4. Create multi-channel input (RGB + DCT + edges)
5. Run Spatiotemporal model --> video_score
6. Run GAN Fingerprint model --> frame_scores
7. Run GAN Family model --> family prediction
8. Run Fusion model --> final_score
9. Return result with all scores and predictions

DETECT IMAGE FLOW:
1. Load image
2. Extract face
3. Create multi-channel input
4. Run GAN Fingerprint model --> score
5. Run GAN Family model --> family prediction
6. Return result

================================================================================
                         HOW TO USE THE SYSTEM
================================================================================

1. SETUP (First time only):
   python setup.py
   
   This installs all dependencies with fallback logic.

2. START THE BACKEND:
   cd deepfake_detection
   python -m src.api.main
   
   Server starts at http://localhost:8000

3. START THE FRONTEND:
   cd frontend
   npm install
   npm run dev
   
   Opens at http://localhost:3000

4. UPLOAD A FILE:
   - Login or register
   - Choose detection type:
     * Image Analysis - for deepfake images
     * Video Analysis - for deepfake videos
     * AI-Generated Detection - for AI art (NEW!)
   - Drag and drop file or browse
   - Click Analyze/Detect

5. VIEW RESULTS:
   - See REAL/DEEPFAKE or AI-Generated/Natural verdict
   - Check confidence scores
   - View individual check breakdowns (for AI detection)
   - View GAN family prediction (for deepfakes)
   - Download PDF report
   - Check history for past analyses

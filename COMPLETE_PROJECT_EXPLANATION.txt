================================================================================
                        SYSTEM ARCHITECTURE
================================================================================

The system uses a MULTI-MODEL ENSEMBLE APPROACH with 5 detection models:

================================================================================
MODEL 1: SPATIOTEMPORAL MODEL (VIDEO ANALYSIS)
================================================================================

PURPOSE: Detect temporal inconsistencies in videos

HOW IT WORKS:

Video Input (e.g., 16 frames)
    ↓
Face Detection (MediaPipe) → Extract faces from each frame
    ↓
Optical Flow Computation → Analyze motion between frames
    ↓
ResNet18 CNN Backbone → Extract spatial features (512D per frame)
    ↓
Optical Flow Encoder → Extract motion features (128D per frame)
    ↓
Feature Fusion → Combine spatial + motion (256D per frame)
    ↓
Bidirectional LSTM (2 layers, 256 hidden units)
    ↓
Temporal Attention → Focus on suspicious frames
    ↓
Classification Head → [Real/Fake probability]

KEY TECHNOLOGIES:
- ResNet18 - Pretrained on ImageNet, feature extractor
- Bi-LSTM - Processes sequences forward and backward
- Optical Flow (Farneback algorithm) - Tracks pixel motion between frames
- Temporal Attention - Learns which frames are most important

WHY IT WORKS: 
Deepfakes have unnatural blinking patterns, inconsistent head movements, 
and temporal jitter. The LSTM captures these patterns.

RESULTS: 98.33% accuracy

FILE: src/models/spatiotemporal_model.py
CHECKPOINT: checkpoints/spatiotemporal/best_model.pt

================================================================================
MODEL 2: GAN FINGERPRINT MODEL (IMAGE ANALYSIS)
================================================================================

PURPOSE: Detect GAN artifacts in images/frames

HOW IT WORKS:

Image Input (224×224)
    ↓
Multi-Channel Preprocessing:
    - RGB (3 channels)
    - YCbCr color space (Cb, Cr = 2 channels)
    - DCT high frequency (1 channel)
    - Edge features: Sobel X, Sobel Y, Laplacian (3 channels)
    = TOTAL: 9 channels
    ↓
Three-Branch Architecture:
    ↓
Branch 1: RGB + Color → EfficientNet-B0 backbone
Branch 2: DCT Frequency → Custom CNN (detects checkerboard artifacts)
Branch 3: Edge Features → Custom CNN (detects unnatural edges)
    ↓
Feature Fusion → Concatenate all branch outputs
    ↓
Classification Head → [Real/Fake probability]

KEY TECHNOLOGIES:
- EfficientNet-B0 - Efficient CNN architecture from Google
- DCT (Discrete Cosine Transform) - Frequency domain analysis
- YCbCr Color Space - Better for compression artifact detection
- Sobel/Laplacian Filters - Edge detection operators

WHY IT WORKS: 
GANs leave "fingerprints":
- Checkerboard patterns in frequency domain (from upsampling)
- Unnatural color distributions in Cb/Cr channels
- Over-smooth or artificially sharp edges

RESULTS: 
- 94.97% accuracy (StyleGAN dataset)
- 100% accuracy (PGGAN+StyleGAN combined)

FILE: src/models/gan_fingerprint_model.py
CHECKPOINT: checkpoints/gan_fingerprint/best_model.pt

================================================================================
MODEL 3: FUSION MODEL (DECISION COMBINER)
================================================================================

PURPOSE: Intelligently combine predictions from Models 1 & 2

HOW IT WORKS:

Input Features (5 values):
    1. video_fake_prob (from spatiotemporal model)
    2. mean_frame_prob (average frame scores)
    3. std_frame_prob (variation in scores)
    4. max_frame_prob (most suspicious frame)
    5. min_frame_prob (least suspicious frame)
    ↓
MLP Architecture:
    Linear(5 → 32) + ReLU + Dropout(0.3)
    ↓
    Linear(32 → 16) + ReLU + Dropout(0.3)
    ↓
    Linear(16 → 2) → [Real/Fake]

WHY IT WORKS: 
- Some deepfakes have good temporal consistency but poor frame quality
- Others have good frames but temporal glitches
- Fusion learns optimal weighting automatically

RESULTS: 98.33% accuracy (best at epoch 7)

FILE: src/models/fusion_model.py
CHECKPOINT: checkpoints/fusion/best_model.pt

================================================================================
MODEL 4: GAN FAMILY CLASSIFIER
================================================================================

PURPOSE: Identify which GAN created the fake (forensic analysis)

ARCHITECTURE: Same as Model 2 but with 5-class output:
- Real
- StyleGAN
- ProGAN
- PGGAN
- Other

USE CASE: Attribution - helps identify the source of fake content

FILE: src/models/gan_family_model.py
CHECKPOINT: checkpoints/gan_fingerprint_family/best_model.pt

================================================================================
MODEL 5: AI-GENERATED IMAGE DETECTOR
================================================================================

PURPOSE: Detect AI-generated images (DALL-E, Midjourney, etc.)

MULTI-CHECK SYSTEM (5 independent analyses):

1. NEURAL NETWORK (Keras CNN) - 30% weight
   - Custom CNN trained on AI vs Natural images
   - Input: 128×128 RGB
   - Threshold: 65% (stricter to reduce false positives)

2. FREQUENCY ANALYSIS (FFT) - 20% weight
   - Low/High frequency ratio
   - AI images have less high-frequency noise

3. NOISE ANALYSIS - 18% weight
   - Variance of variance in local patches
   - AI images have uniform noise patterns

4. COLOR DISTRIBUTION - 17% weight
   - LAB color space entropy
   - Saturation variance analysis
   - AI images have unnatural color consistency

5. EDGE ANALYSIS - 15% weight
   - Canny edge smoothness
   - AI images have over-smooth or artificially sharp edges

DECISION LOGIC:
- Majority Voting: 3+ checks agree → Final decision
- Confidence Levels:
  * Very High: 5/5 checks agree
  * High: 4/5 checks agree
  * Medium: 3/5 checks agree

WHY IT WORKS: 
Multiple independent signals are harder to fool. Even if one check fails, 
others compensate.

FILES: 
- Photo_Detector/multi_check_detector.py
- src/api/ai_generated/multi_check_detector.py
- src/api/ai_generated/image_classifier_model.keras

Two Parallel Paths:

Path 1: Deepfake Detection

================================================================================
                    KEY CONCEPTS & TECHNIQUES
================================================================================

1. CONVOLUTIONAL NEURAL NETWORKS (CNN)
--------------------------------------

WHAT IT DOES: Extracts features from images hierarchically

LAYERS:
- Convolutional layers - Detect patterns (edges, textures, objects)
- Pooling layers - Reduce spatial dimensions, keep important info
- Activation functions (ReLU) - Add non-linearity
- Fully connected layers - Classification

USED IN: All models as feature extractors

SIMPLE EXPLANATION:
Imagine you're trying to identify if a photo is REAL or FAKE:

STEP 1: Look at small details (edges, lines)
STEP 2: Combine details to see textures (skin, hair)
STEP 3: Combine textures to see parts (eyes, nose, mouth)
STEP 4: Combine parts to understand the whole face
STEP 5: Make a decision: REAL or FAKE

This is exactly what CNN does, layer by layer!

2. RECURRENT NEURAL NETWORKS (LSTM)
-----------------------------------

WHAT IT DOES: Processes sequential data (video frames)

WHY LSTM:
- Has memory - remembers previous frames
- Bidirectional - looks forward and backward in time
- Captures temporal dependencies

USED IN: Spatiotemporal Model

HOW IT WORKS:
Frame 1 → LSTM → Memory State 1
Frame 2 + Memory State 1 → LSTM → Memory State 2
Frame 3 + Memory State 2 → LSTM → Memory State 3
...
Final Memory State → Classification

3. OPTICAL FLOW
--------------

WHAT IT DOES: Tracks pixel movement between frames

ALGORITHM: Farneback (dense optical flow)

WHY IT WORKS: Deepfakes have unnatural motion patterns
- Real: Smooth, continuous motion
- Fake: Jittery, inconsistent motion, sudden jumps

USED IN: Spatiotemporal Model preprocessing

VISUALIZATION:
Frame 1: Person's face at position A
Frame 2: Person's face at position B
Optical Flow: Vector field showing how each pixel moved from A to B

4. FREQUENCY DOMAIN ANALYSIS
----------------------------

TECHNIQUES:
- DCT (Discrete Cosine Transform) - Used in JPEG compression
- FFT (Fast Fourier Transform) - Frequency spectrum analysis

WHY IT WORKS: 
GANs produce periodic artifacts invisible to human eyes. These show up as
patterns in frequency domain.

USED IN: GAN Fingerprint Model, AI-Generated Detector

SIMPLE EXPLANATION:
Every image can be broken down into frequencies:
- Low frequency: Smooth areas, general shapes
- High frequency: Details, edges, noise

GAN images have unusual frequency patterns:
- Too smooth (missing high frequencies)
- Checkerboard artifacts (specific frequency peaks)

5. MULTI-COLOR SPACE ANALYSIS
-----------------------------

COLOR SPACES USED:
- RGB - Standard red-green-blue
- YCbCr - Luminance (Y) + Chrominance (Cb, Cr)
- LAB - Perceptually uniform color space

WHY IT WORKS: 
Compression artifacts and GAN fingerprints appear differently in each space

USED IN: GAN Fingerprint Model, AI-Generated Detector

EXAMPLE:
RGB: Shows visible colors
YCbCr: Better for detecting JPEG compression artifacts
LAB: Better for perceptual color differences

6. TRANSFER LEARNING
-------------------

CONCEPT: Use pretrained models as starting point

MODELS USED:
- ResNet18 - Pretrained on ImageNet (1.2M images)
- EfficientNet-B0 - Efficient architecture from Google

BENEFIT: 
- Faster training
- Better accuracy
- Less data needed

HOW IT WORKS:
1. Take model trained on millions of general images
2. Remove last classification layer
3. Add new layer for deepfake detection
4. Fine-tune on deepfake dataset

7. ENSEMBLE LEARNING
-------------------

CONCEPT: Combine multiple models for better predictions

YOUR APPROACH:
- Train separate models for different signals
- Fusion network learns optimal combination
- Multi-check system for AI-generated images

BENEFIT: More robust, catches different types of fakes

ANALOGY:
Like having multiple doctors examine a patient:
- One checks symptoms
- One checks blood tests
- One checks X-rays
- All opinions combined → More accurate diagnosis

WHAT THESE METRICS MEAN
-----------------------

ACCURACY: 
    Overall correctness (96+ out of 100 predictions correct)
    Formula: (Correct Predictions) / (Total Predictions) × 100

PRECISION: 
    When model says "FAKE", it's right 96.77% of time
    Formula: True Positives / (True Positives + False Positives)
    
RECALL: 
    Catches 100% of actual fakes (no false negatives)
    Formula: True Positives / (True Positives + False Negatives)
    
F1 SCORE: 
    Balanced measure (harmonic mean of precision & recall)
    Formula: 2 × (Precision × Recall) / (Precision + Recall)
    
ROC-AUC: 
    99.74% = Excellent discrimination ability
    Measures how well model distinguishes classes
    1.0 = Perfect, 0.5 = Random guess

Actual Fake             0              150

This shows:
- 145 real videos correctly identified (True Negatives)
- 150 fake videos correctly identified (True Positives)
- 5 real videos misclassified as fake (False Positives)
- 0 fake videos missed (False Negatives) - Perfect recall!

================================================================================
                    COMMON QUESTIONS & ANSWERS
================================================================================

Q: Why use both CNN and LSTM?
A: CNNs extract spatial features from individual frames (what's in the image),
   while LSTMs capture temporal patterns (how frames change over time). 
   Deepfakes often have good spatial quality but poor temporal consistency.

Q: What is optical flow and why is it important?
A: Optical flow tracks pixel movement between frames. Real videos have smooth,
   consistent motion. Deepfakes have jittery, inconsistent motion due to 
   frame-by-frame generation artifacts.

Q: Why analyze frequency domain?
A: Many GAN artifacts are invisible to human eyes but show up as patterns in
   frequency domain. For example, checkerboard artifacts from upsampling 
   create specific frequency peaks.

Q: What's the difference between deepfake and AI-generated detection?
A: Deepfakes replace faces in real videos. AI-generated images are created 
   from scratch by models like DALL-E. Different artifacts, different 
   detection methods.

Q: Can the system detect future/unknown GANs?
A: Yes, to some extent. Frequency analysis and multi-check system work on 
   general GAN artifacts, not specific to one architecture. However, 
   retraining on new GAN samples improves accuracy.

Q: How does the multi-check system reduce false positives?
A: By requiring agreement from multiple independent methods. If only 1-2 
   checks flag an image but others don't, confidence is low. All 5 agreeing 
   means very high confidence.

Q: What hardware is needed to run inference?
A: CPU is sufficient for inference (1-2 seconds per image, 10-30 seconds per 
   video). GPU speeds it up to milliseconds per image.

Q: Can it run in real-time?
A: For images, yes (with GPU). For videos, near real-time is possible with 
   optimizations like frame skipping and lower resolution.

Q: How long did training take?
A: Spatiotemporal: ~8-12 hours on 4GB GPU
   GAN Fingerprint: ~4-6 hours
   Fusion: ~1-2 hours
   Total: ~15-20 hours across all models

Q: What's the false positive rate?
A: With 96.77% precision, false positive rate is ~3.23%. This means about 3 
   out of 100 real images might be incorrectly flagged as fake.

SYSTEM REQUIREMENTS

INSTALLATION STEPS
-----------------

1. Clone repository:
    git clone <repository-url>
    cd Project

2. Create virtual environment:
    python -m venv venv
    venv\Scripts\activate  (Windows)
    source venv/bin/activate  (Linux/Mac)

3. Install dependencies:
    pip install -r requirements.txt

4. Download pretrained models (if not training):
    Place checkpoints in checkpoints/ directory

5. Run backend:
    python run_production.py

6. Run frontend (choose one):
    # React dashboard
    cd frontend
    npm install
    npm run dev
    
    # Flask web app
    python Photo_Detector/app.py
    
    # Gradio interface
    python -m ui.app_gradio

COMMON INSTALLATION ISSUES
--------------------------

1. CUDA not found:
   - Install CUDA toolkit matching PyTorch version
   - Set CUDA_HOME environment variable

2. MediaPipe installation fails:
   - Try: pip install mediapipe --no-deps
   - Fall back to OpenCV Haar cascade

3. Out of memory during training:
   - Reduce batch size in config
   - Enable gradient accumulation
   - Use mixed precision training

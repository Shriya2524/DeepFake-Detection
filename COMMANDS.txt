================================================================================
                        DETAILED SETUP GUIDE
================================================================================

------------------------------------------------------------------------------
STEP 1: PREREQUISITES
------------------------------------------------------------------------------

Make sure you have installed:
  - Python 3.8 or higher
  - Node.js 16 or higher
  - npm (comes with Node.js)
  - Git (for version control)

Check versions:
  python --version      # Should be 3.8+
  node --version        # Should be 16+
  npm --version         # Should be 8+

------------------------------------------------------------------------------
STEP 2: CLONE/DOWNLOAD PROJECT
------------------------------------------------------------------------------

If you haven't already:
  git clone <repository-url>
  cd deepfake_detection

Or if you received the project as a zip:
  # Extract the zip file
  cd deepfake_detection

------------------------------------------------------------------------------
STEP 3: AUTOMATIC SETUP (RECOMMENDED)
------------------------------------------------------------------------------

Run the setup script which handles everything automatically:

  python setup.py

This will:
  1. Create Python virtual environment (optional)
  2. Install all Python dependencies with fallback logic
  3. Install Node.js dependencies for frontend
  4. Verify all model files are present
  5. Test imports and configurations

If setup.py fails on any step, it will show specific error and suggestion.

------------------------------------------------------------------------------
STEP 4: MANUAL SETUP (If automatic fails)
------------------------------------------------------------------------------

4a. Python Dependencies:

  # Option 1: With virtual environment (recommended)
  python -m venv venv
  
  # On Windows:
  venv\Scripts\activate
  
  # On Mac/Linux:
  source venv/bin/activate
  
  # Install dependencies
  pip install -r requirements.txt

  # Option 2: Without virtual environment
  pip install -r requirements.txt

4b. Frontend Dependencies:

  cd frontend
  npm install

4c. If TensorFlow fails:

  # Try CPU-only version
  pip uninstall tensorflow
  pip install tensorflow-cpu

4d. If PyTorch fails:

  # Try CPU-only version
  pip uninstall torch torchvision
  pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu


================================================================================
                        RUNNING THE APPLICATION
================================================================================

------------------------------------------------------------------------------
METHOD 1: USING TWO TERMINALS (RECOMMENDED)
------------------------------------------------------------------------------

Terminal 1 - Backend:
  cd deepfake_detection
  python -m src.api.main
  
  # You should see:
  # * Running on http://127.0.0.1:8000
  # * Running on http://192.168.x.x:8000

Terminal 2 - Frontend:
  cd deepfake_detection/frontend
  npm run dev
  
  # You should see:
  # VITE v5.x.x ready
  # Local: http://localhost:3000/

Now open http://localhost:3000 in your browser!

------------------------------------------------------------------------------
METHOD 2: USING BACKGROUND PROCESSES
------------------------------------------------------------------------------

On Windows (PowerShell):
  # Start backend in background
  Start-Process python -ArgumentList "-m src.api.main" -WindowStyle Hidden
  
  # Start frontend
  cd frontend
  npm run dev

On Mac/Linux:
  # Start backend in background
  python -m src.api.main &
  
  # Start frontend
  cd frontend
  npm run dev

================================================================================
                        TROUBLESHOOTING COMMANDS
================================================================================

------------------------------------------------------------------------------
ISSUE: "Module not found" error
------------------------------------------------------------------------------

  # Make sure you're in the project root
  cd deepfake_detection
  
  # Check if dependencies are installed
  pip list | grep torch
  pip list | grep tensorflow
  
  # Reinstall if missing
  pip install -r requirements.txt

------------------------------------------------------------------------------
ISSUE: "Port already in use" error
------------------------------------------------------------------------------

On Windows:
  # Find process using port 8000
  netstat -ano | findstr :8000
  
  # Kill the process (replace PID with actual number)
  taskkill /PID <PID> /F

On Mac/Linux:
  # Find and kill process on port 8000
  lsof -ti:8000 | xargs kill -9

------------------------------------------------------------------------------
ISSUE: "CUDA out of memory" error
------------------------------------------------------------------------------

  # Use CPU instead (slower but works)
  export CUDA_VISIBLE_DEVICES=""
  python -m src.api.main

Or in the code, models will automatically fallback to CPU.

------------------------------------------------------------------------------
ISSUE: "Permission denied" error (npm)
------------------------------------------------------------------------------

On Windows:
  # Run PowerShell as Administrator
  
On Mac/Linux:
  sudo npm install

------------------------------------------------------------------------------
ISSUE: Frontend shows "Failed to fetch"
------------------------------------------------------------------------------

1. Make sure backend is running on port 8000
2. Check CORS settings in src/api/main.py
3. Try accessing backend directly:
   curl http://localhost:8000/health

------------------------------------------------------------------------------
ISSUE: Models not loading
------------------------------------------------------------------------------

  # Check if model files exist
  dir checkpoints\spatiotemporal\best_model.pt
  dir checkpoints\gan_fingerprint\best_model.pt
  dir checkpoints\fusion\best_model.pt
  dir src\api\ai_generated\image_classifier_model.keras

  # If missing, re-download or retrain models

------------------------------------------------------------------------------
SCRIPT: Check System Status
------------------------------------------------------------------------------

Create a file called check_status.py:

  import requests
  import sys
  
  def check_status():
      try:
          r = requests.get('http://localhost:8000/health', timeout=5)
          if r.status_code == 200:
              print("✓ Backend is running")
          else:
              print("✗ Backend returned error:", r.status_code)
      except:
          print("✗ Backend is not running")
      
      try:
          r = requests.get('http://localhost:3000', timeout=5)
          if r.status_code == 200:
              print("✓ Frontend is running")
          else:
              print("✗ Frontend returned error:", r.status_code)
      except:
          print("✗ Frontend is not running")
  
  if __name__ == "__main__":
      check_status()

Run with: python check_status.py

================================================================================
                        WHAT IS CNN?
================================================================================

CNN stands for CONVOLUTIONAL NEURAL NETWORK

In simple terms:
  - A CNN is a type of artificial intelligence that can "see" and understand 
    images, just like humans do.
  - It learns to recognize patterns in images by looking at many examples.
  - It's the most popular deep learning model for image-related tasks.

Real-world examples where CNN is used:
  - Face recognition in your phone
  - Self-driving cars (detecting objects)
  - Medical image analysis (detecting diseases)
  - Deepfake detection (your project!)
  - AI-Generated image detection (NEW!)


================================================================================
                    HOW CNN WORKS (SIMPLE EXPLANATION)
================================================================================

Imagine you're trying to identify if a photo is REAL or FAKE:

STEP 1: Look at small details (edges, lines)
STEP 2: Combine details to see textures (skin, hair)
STEP 3: Combine textures to see parts (eyes, nose, mouth)
STEP 4: Combine parts to understand the whole face
STEP 5: Make a decision: REAL or FAKE

This is exactly what CNN does, layer by layer!

================================================================================

                    |

                    |
                    v
    +-----------------------------------------------+
    |           CONVOLUTIONAL LAYER 2               |
    |  - Detects: Textures, Patterns                |
    |  - Combines edges into more complex shapes    |
    |  - Output: 128 feature maps                   |
    +-----------------------------------------------+
                    |
                    v
    +-----------------------------------------------+
    |              POOLING LAYER 2                  |
    |  - Further reduces size                       |
    |  - Output: 56 x 56 x 128                      |
    +-----------------------------------------------+
                    |
                    v
    +-----------------------------------------------+
    |           CONVOLUTIONAL LAYER 3+              |
    |  - Detects: Complex patterns                  |
    |  - Eyes, nose, mouth, facial features         |

    +-----------------------------------------------+
                    |
                    v
    +-----------------------------------------------+

================================================================================
                    KEY CNN COMPONENTS EXPLAINED
================================================================================

1. CONVOLUTIONAL LAYER
----------------------
What it does: Scans the image with small filters to detect patterns

Example (3x3 filter for edge detection):
  
  Filter:          Image patch:       Result:
  [-1  0  1]       [100 100 200]      
  [-1  0  1]   *   [100 100 200]  =   Strong vertical edge detected!
  [-1  0  1]       [100 100 200]      

The CNN learns hundreds of these filters automatically during training!


2. POOLING LAYER (Max Pooling)
------------------------------
What it does: Shrinks the image while keeping important features

Example (2x2 max pooling):
  
  Before:              After:
  [1  3  2  4]         [3  4]
  [5  6  7  8]   -->   [6  8]
  [1  2  3  4]
  [5  6  7  8]

Takes the maximum value from each 2x2 region.


3. ACTIVATION FUNCTION (ReLU)
-----------------------------
What it does: Adds non-linearity (allows CNN to learn complex patterns)

ReLU = Rectified Linear Unit
  - If value > 0: keep it
  - If value < 0: make it 0

Example: [-2, 5, -1, 3] --> [0, 5, 0, 3]


4. FULLY CONNECTED LAYER
------------------------
What it does: Combines all learned features to make final decision

Like a voting system:
  - "I see smooth skin texture" --> might be fake
  - "I see natural eye reflections" --> might be real
  - "I see unnatural hair edges" --> might be fake
  - Final vote: 95% FAKE

  ```python
  import torchvision.models as models
  
  # Load pre-trained EfficientNet
  self.backbone = models.efficientnet_b0(weights='IMAGENET1K_V1')
  
  # Modify first layer to accept 9 channels instead of 3

  self.backbone.features[0][0] = nn.Conv2d(
      in_channels=9,  # 9-channel input
      out_channels=32,
      kernel_size=3,
      stride=2,
      padding=1
  )
  ```

Input: 9-channel image
  - Channels 0-2: RGB (Red, Green, Blue)
  - Channels 3-4: Cb, Cr (color difference)
  - Channel 5: DCT (frequency features)
  - Channels 6-8: Edge maps (Sobel X, Sobel Y, Laplacian)

3. AI-GENERATED DETECTION (MULTI-CHECK SYSTEM) - NEW!
------------------------------------------------------------------------------

File: src/api/ai_generated/multi_check_detector.py

CNN Backbone: Custom Keras CNN Model
  - Trained specifically for AI vs Natural image detection
  - Input size: 128x128 pixels
  - Binary classification: AI_Generated or Natural

What it detects:
  - DALL-E generated images
  - Midjourney generated images
  - Stable Diffusion generated images
  - Other AI art generators

Multi-Check Analysis (5 methods combined):
  1. Neural Network Prediction (CNN) - Primary classifier
  2. Frequency Analysis (FFT) - Detects AI patterns in frequency domain
  3. Noise Pattern Analysis - AI images have unusual noise uniformity
  4. Color Distribution - AI images have unnatural color histograms
  5. Edge Characteristics - AI edges are smoother/different than natural

Code snippet:
  ```python
  # From src/api/ai_generated/multi_check_detector.py
  from tensorflow import keras
  
  class MultiCheckDetector:
      def __init__(self, model):
          self.model = model  # Keras CNN model
          
      def check_model_prediction(self, img_array):
          # Resize to 128x128 for the CNN
          img_resized = cv2.resize(img_array, (128, 128))
          img_normalized = img_resized / 255.0
          img_batch = np.expand_dims(img_normalized, axis=0)
          
          # Get CNN prediction
          prediction = self.model.predict(img_batch, verbose=0)
          ai_prob = float(prediction[0][0])
          natural_prob = float(prediction[0][1])
          
          return {
              'method': 'Neural Network',
              'is_ai': ai_prob > 0.50,
              'ai_probability': ai_prob,
              'natural_probability': natural_prob
          }
  ```

How Multi-Check Voting Works:
  - Each of the 5 checks votes: "AI" or "Natural"
  - If 3+ checks vote AI --> classified as AI-Generated
  - Weights: Neural (30%), Frequency (20%), Noise (18%), Color (17%), Edge (15%)
  - Final score = weighted average of all check scores

                    WHY CNN FOR DEEPFAKE DETECTION?
================================================================================

1. PATTERN RECOGNITION
   - CNNs excel at finding subtle patterns
   - GAN-generated images have specific "fingerprints"
   - CNN can learn to detect these automatically

   - Low-level: edges, colors, textures
   - Mid-level: facial features, skin patterns
   - High-level: face structure, identity

3. TRANSFER LEARNING

   - Fine-tune on deepfake dataset
   - Faster training, better results

4. MULTI-CHANNEL INPUT
   - Can process RGB + frequency + edge information
   - More features = better detection


================================================================================
                    WHY CNN FOR AI-GENERATED IMAGE DETECTION?
================================================================================

1. FREQUENCY FINGERPRINTS
   - AI generators (DALL-E, Midjourney) leave patterns in frequency domain
   - CNN combined with FFT analysis catches these patterns

2. NOISE UNIFORMITY
   - Real photos have natural sensor noise (varies across image)
   - AI images have artificial, uniform noise patterns
   - CNN learns to detect this difference

3. COLOR DISTRIBUTION
   - Real photos have natural color histograms
   - AI images often have unusual color distributions
   - CNN analyzes LAB/HSV color spaces

4. EDGE CHARACTERISTICS
   - Real photo edges come from real-world objects
   - AI-generated edges are mathematically smoother
   - Canny edge detection + CNN analysis


================================================================================
                    CNN TRAINING PROCESS
================================================================================

1. FORWARD PASS
   - Input image goes through all CNN layers
   - Output: Prediction (Real or Fake probability)

2. LOSS CALCULATION
   - Compare prediction with actual label
   - Loss = how wrong the prediction was
   - Your project uses: Focal Loss (handles imbalanced data)

3. BACKWARD PASS (Backpropagation)
   - Calculate how to adjust each filter
   - Gradient descent: small steps toward better accuracy

4. UPDATE WEIGHTS
   - Adjust all CNN filters slightly
   - Optimizer used: AdamW

5. REPEAT
   - Process thousands of images
   - Each full pass = 1 epoch
   - Your models trained for 10-50 epochs


================================================================================
                    CNN OUTPUT INTERPRETATION
================================================================================

The CNN outputs 2 values (logits):

Example output: [−2.5, 3.8]

After Softmax (convert to probabilities):
  - REAL probability: 0.02 (2%)
  - FAKE probability: 0.98 (98%)

Final prediction: FAKE (98% confidence)
